Data source

Option A — Published Google Sheet

In your sheet: File → Share → Publish to web → choose the tab → CSV → Publish. Copy the link it gives you (it ends in output=csv) and paste it here. Sharing the normal edit link won't work — it has to be the published one.

Showing demo data.

Option B — Upload a TalkWalker CSV

One row per mention. Needs: date, brand, topic, sentiment, engagement. Optional: content, channel, url. Order doesn't matter.

Option C — Paste the data

Copy the cells straight out of Sheets (including the header row) and paste here. Always works, no permissions needed. Your sheet's column order — Post ID · Date · Platform · Post Text · Sentiment · Topic · Brand · Engagement — is read as-is. Empty trailing columns are ignored.
